## 一、视觉升级

### 1. 卡片悬浮与图片微动（三页统一）

- `.material-card`、后台 `.stat-card` / `.overview-card` / `.panel`、`.table-wrap` 悬浮时 `translateY(-6px)`（面板为 -4px），阴影切换为更深的 `--shadow-lift`。
- 素材卡片图片在悬浮时 `scale(1.055)` 并轻微提饱和/对比，形成立体悬浮感。
- `@media (prefers-reduced-motion: reduce)` 内统一关闭位移与缩放，仅保留颜色/阴影过渡；已用 Playwright 的 `reduced_motion="reduce"` 实测：卡片 `transform` 为 `none`。

### 2. 顶部红色导航吸顶

- `.top-bar`（含 `.admin-top-bar`）改为 `position: sticky; top: 0`，底色为半透明深红渐变 + `backdrop-filter: blur(18px) saturate(1.55)`，底部细金线 + 柔和投影。
- 滚动超过 12px 由 `js/front-common.js` 添加 `.is-scrolled`，底色加深、投影加强，形成清晰的层级分隔。
- 修复：原 `html/body` 的 `overflow-x: hidden` 会让 `position: sticky` 失效，已改为 `overflow-x: clip`。

### 3. 毛玻璃卡片

- 新增变量：`--glass-bg`、`--glass-border`、`--glass-shadow`、`--shadow-lift`、`--ease-soft`（定义于 `css/common.css`）。
- 卡片背景为低透明度暖白渐变，`backdrop-filter: blur(16px) saturate(1.35)`，1px 细边框 + 「内高光 + 近投影 + 远投影」双层阴影。
- 页面底层加了极淡的红金径向渐变与 1px 网点纹理，使毛玻璃有可感知的透出层次。

### 4. 间距与留白

- 素材墙 `gap` 提升到 `32px 28px`，卡片信息区固定最小高度（232px），文字四周 22–24px 内边距。
- 后台指标卡 24px 内边距、卡片间距 22px；面板 20–22px；表格单元格收紧到 11–18px 视宽度分档。
- 全站卡片、筛选卡、面板均不贴边；移动端 `page` 左右留白 16px，卡片内部 18px。

### 5. 排版主次

- 首页主标题 `clamp(38px, 4.4vw, 58px)` / 900 字重 / 5px 字距，副标题分级（18px 主、14.5px 次）；区块标题用金色渐变竖条 + 900 字重。
- 详情页标题 34px / 900 字重（≤1100 收至 30px），正文 15px + 1.9 行高，导语为左侧红竖线引用块，来源行 12px 弱化。
- 后台标题 27px，指标数字 33px 等宽数字（`font-variant-numeric: tabular-nums`）防跳动。

### 6. 素材图片统一

- 所有素材卡、TOP5 卡、详情封面统一 `aspect-ratio: 16 / 10` + `object-fit: cover` + 圆角，图片源文件统一裁切为 1200×750。
- 校验：50 张图片尺寸集合 = `{(1200, 750)}`。

### 7. 按钮质感

- 主按钮加顶部高光内阴影 + 双层外投影 + 悬浮上浮 2px 提亮 + 按下回落并转内阴影，悬浮时有一道掠过式高光；键盘聚焦有可见描边；搜索按钮在移动端自动满宽。

### 8. 整体质感

- 统一 18px 大圆角、暖金细线、分层阴影与克制的动效曲线 `cubic-bezier(.22,.68,.28,1)`；去掉模板化的平涂与硬阴影。

### 9. 响应式修正（本轮自查发现并修复）

- 后台热度 TOP5 表：桌面「类型」列折行、768 表格被挤出容器、375 末位数字被裁 —— 通过「类型列 `nowrap` + 标题列宽 36%」「≤1100 单列看板 + 表格紧凑内边距」「≤480 覆盖 `.hot-table` 的 18px 单元格内边距、缩小排名徽标、隐藏类型/下载量列」修复；三档实测 `table-wrap` 溢出均为 0。
- 首页平板档 TOP5 小卡：文字改为垂直居中，消除卡片下部大片空白。
- 375 首页副标题由两行改为单行；375 hero 标题单行不出现单字换行。

## 三、详情页 AI 助手

- 右下角固定悬浮入口（`#ai-launch`，红金渐变胶囊按钮 + 说话气泡图标 + 「AI 助手」，移动端收起文字仅留圆形图标），不遮挡正文主区域。
- 点击弹出类 ChatGPT 聊天面板（`#ai-panel`）：顶部标题栏、消息流、输入区、发送按钮；`×` 可收起，再次点击悬浮按钮可重新弹出（保留会话内容）。
- 发送后立即插入「AI 思考中」三点跳动动画，**1.5 秒**后自动回复。
- 关键词匹配：
  - 含「长征」→ 推荐长征相关素材（含可点击详情链接）；
  - 含「毛泽东」→ 推荐毛泽东相关有声素材，并内嵌可试听的音频播放器；
  - 其他内容 → 返回通用推荐话术 + 热门素材推荐。
- 移动端面板自适应为 `left/right 12px` + 高度 `min(70vh, 100vh-120px)`。
- 宽屏（≥1181px）打开面板时给 `body` 加 `ai-open`，正文容器右侧让出 426px，面板与正文卡片实测间距 56px，不遮挡内容；窄屏仍为可关闭的浮层。
- 卡片日期字段标签统一为「上传日期」，避免与史料发生时间混淆（素材文案中的历史年份均在正文内）。
