# 红色文化数字基因库 · 项目骨架与分工说明

> 用途：开工前两人共同对齐的公共文件。本目录上传 GitHub 公共仓库后，队友 clone 即可在同一份结构上开发。
> 交付截止：11 月 17 日。最终只交**源码**，本地双击 html 即可运行，浏览器截屏放进 PPT；不部署、不给外部链接。

## 一、技术形式

- 纯 **HTML + CSS + 原生 JavaScript**，不用框架、不用打包工具、不用 Node。
- 数据存浏览器 **localStorage**（演示用假数据，刷新不丢）；**不接真实后端接口、不建数据库、不做登录**。
- 后台图表如需要环形/柱状图，可用 ECharts CDN 引入，不引入 Vue 等框架。

## 二、目录结构

```
红色素材库/
├── index.html          前台首页（素材卡片墙）
├── detail.html         素材详情页（大图、简介、元信息、音频、下载）
├── admin.html          管理后台（数据看板 + 素材管理，两个板块/标签）
├── css/
│   └── common.css      共用：配色、字号、卡片、按钮、表格样式（两人都不私改）

└── assets/
    ├── images/         6 张素材配图（01–06，png）
    ├── audio/          2 条素材音频（仅第 1、2 条，mp3）
    ├── docs/           6 份原始文档（甲方提供）
    └── reference/      甲方给的 5 张页面参考图（配色布局参照，不抄图中名称与数字）
```

## 三、要做的页面（共 4 块）

1. **素材首页 `index.html`**：搜索框、筛选下拉、系列标签、素材卡片墙；点卡片进详情页。
2. **素材详情页 `detail.html`**：大图 + 标题 + 元信息（系列/类型/供稿人/地点/日期/浏览/下载）+ 标签 + 简介；有音频的显示播放器；下载按钮取原始文档。
3. **后台数据看板**：统计卡片（素材总数、已入库、累计浏览、累计下载等）+ 热度 TOP5 表格（可选 ECharts 图表）。
4. **后台素材管理**：素材列表表格（标题、供稿人、类型、状态、更新日期、预览/下载）+「上传素材」按钮。

## 四、明确不做的内容（导航里如需保留文字，只做外观占位，不实现功能）

- 审核队列
- 排行榜独立页面（详情页不出现"查看排行榜"按钮）
- 我的投稿
- 登录 / 注册 / 账号权限 / 退出登录
- 服务器部署、外部可访问链接、真实后端接口、数据库

## 五、上传联动规则（必须实现）

后台「上传素材」选择本地图片、填写标题等信息并保存后：

1. 后台素材管理列表**新增一行**；
2. 回到首页，卡片墙**新增一张卡片**；
3. 后台看板素材总数、浏览/下载等统计**同步 +1**；
4. 新素材写入 **localStorage**，刷新页面后仍然存在；
5. 清空浏览器 localStorage 后，回退到 `js/data.js` 里的 6 条初始素材。

实现约定：页面不要各自硬编码素材；统一从 `data.js` 取初始清单，读取时先合并 localStorage 里用户新增的条目。

### 字段定义（`js/data.js` 每条素材）

| 字段 | 含义 |
|---|---|
| id | 编号（1–6），详情页跳转用 |
| title | 标题 |
| author | 供稿人姓名 |
| authorRole | 身份与地区 |
| location | 涉及地点 |
| date | 投稿/更新日期 |
| series | 所属系列（旧址系列 / 革命文物系列） |
| tags | 标签数组 |
| type | 类型数组（文档 / 音频 / 配图） |
| intro | 简介正文（取自原始文档） |
| cover | 配图路径 |
| audio | 音频路径，无音频为空字符串 |
| doc | 原始文档路径 |
| views / downloads | 浏览量 / 下载量（演示占位，初始为 0） |
